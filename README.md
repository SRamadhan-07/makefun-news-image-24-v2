A Python program — standard library only, no network — that sums up the world news of Tuesday 24 November 2026 in one image. It composites four photographic news panels (the Cikande factory fire in Indonesia, Russia's war dead counted from leaked data, the collapsed COP31 climate talks, and bitcoin's worst November since 2018) with hand-drawn vector type into a newspaper front page, "THE WORLD IN ONE DAY", dated Tuesday, 24 November 2026, with five more stories in a briefing band. It writes /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png), byte-identical on every run.

## Run it

```sh
python3 main.py
```
